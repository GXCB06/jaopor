# Disclosure levels: surface audit (R2 step 6)

> 2026-10-11. Every code path that reads a raw metric column, sorted by what happens when migration `20261011130000_disclosure_levels.sql` is applied. **Nothing here has been changed yet** (owner instruction: change surfaces only after the migration is approved). Rules per surface come from `shownOn()` in `src/lib/disclosure.ts` (spec §6).

## How to read the client column

- **anon / cookie:** `createPublicClient` (signed-out reads) or `createClient` (the signed-in user's session). After the migration these **fail with "permission denied"** if they select a raw column, including through `select *` or an embedded `startups(*)`.
- **admin:** `createAdminClient` (service role). It keeps reading raw values, so it **doesn't break**, but anything it renders publicly must apply the levels in code.

## D. Tests to add with the surface work

- e2e: a `badge` project has no figure in the HTML, the RSC payload, the OG image text, `/api/badge` or `/api/share-card`; a `private` project has no stamp at all.
- e2e: boards and directory sort contain only `exact` rows for value boards.
- A lint-style unit test: no file under `src/lib/data` selects a raw metric column through the public client.

## E. Size

About **4–6 working days** for A + B + C + D, plus the owner UI (C9). A and the render switch (C1–C6) must ship **before** the migration is applied, and they need a compatibility layer while both schemas exist: read `public_*` when present, else the raw column. Otherwise the code would break in production before the apply, or the apply would break the code.

## F. Residual risks

1. **Deploy order:** applying before the code switch makes every public page 500 (`select *` denied). Mitigation: the compatibility layer, then apply, then remove the fallback.
2. **Admin-client paths** (B1, B2) bypass the grants: their rules live in code only. Covered by unit tests on `shownOn` and the e2e above.
3. **ISR / CDN cache** keeps an old exact value up to `revalidate = 60` s, and images longer. Mitigation: `revalidatePath` on level change, plus short cache headers on badge / share images.
4. **Advisor:** `get_my_startup_metrics` is a `security definer` function callable by `authenticated`. The advisor may warn. It is scoped to `owner_id = auth.uid()` (T149c / T150). The alternative is the admin client after an ownership check on the server.
5. **Raw `fx_rates` dependency:** with no rate for the sync day or earlier, a `band` choice falls back to `badge` (never to the raw value). The band also moves if the rate changes on the next sync; the rate day is stored in `public_band_fx_day`.
6. **Users / build `growth`:** there is no stored previous period, so `growth` always shows as `badge` for those groups. The chooser should say so (or hide `growth` there).
